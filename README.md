## Doraemon-Like Smart Chatbot for Students

This project focuses on building a smart educational chatbot designed to reduce screen time for students by enabling voice-based interaction and projector-based visual output.

## Key Features

Voice-controlled chatbot that interacts with students without requiring continuous screen usage

Uses a projector to display educational images and content, promoting healthier learning habits

## Objective

The main goal of this project is to support student learning while minimizing mobile and screen dependency through interactive voice commands.

  Technologies (Planned / Used)
  
  Python
  
  Speech Recognition
  
  Text-to-Speech
  
  AI Chatbot Logic
  
  Projector-based Output

## Use Case

Designed for classrooms and home learning environments where screen-free interaction is preferred.

## Steps to Run

Clone the repository

    git clone https://github.com/your-username/doraemon-smart-chatbot.git


Navigate to the project directory

    cd doraemon-smart-chatbot


Install required dependencies

    pip install -r requirements.txt


Connect microphone and projector to the system

  Run the chatbot
    
    python main.py


Speak voice commands to interact with the chatbot
